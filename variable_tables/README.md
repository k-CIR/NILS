# Variable modality tables

This folder contains markdown exports of the modality relevance tables.

## Legend

- `✓` = relevant to the modality
- `—` = not relevant / not represented in the current schema

## BIDS legend

- `sub` = used for subject/session naming
- `participants` = standard `participants.tsv`
- `filename` = used in exported file/folder naming
- `sidecar` = standard JSON / modality metadata
- `channels.tsv` = MEG/EEG channel table
- `coordsystem/channels` = MEG sensor coordinate metadata
- `events/epochs` = event/epoch related files
- `custom` = only if extended beyond core BIDS usage
- `—` = not normally included in BIDS
